Privacy Policy

This privacy statement explains in clear, plain language how user data is utilized on the Welcome to Westville Map Project. We value your privacy and process data solely as necessary to provide features of this website and map.

No Personal Tracking or Collection

This website is a passive, public informational resource. We do not collect, store, track, profile, or sell any personal data. Specifically:

  • We do not set any commercial, tracking, or profiling cookies.
  • We do not integrate third-party web analytics scripts or trackers.
  • We do not require user accounts, emails, or personal login information.

How Geolocation Works (Strictly On-Device)

The interactive map includes a "My Location" button and a "Share my location" feature. These features require your browser's Geolocation API to function:

  • Your exact coordinates are calculated entirely within your web browser on your own device.
  • We do not transmit, save, or log your location coordinates on our backend servers.
  • When you use the "Share my location" button, a custom shareable link is generated locally and copied to your clipboard. This link contains coordinates solely as URL parameters, so anyone you share the link with can see that location, but no location history is recorded by us.

Note on Third-Party Requests: To load map imagery and satellite layers, your browser fetches tiles directly from open tile servers (OpenFreeMap and Esri). These external servers naturally receive standard HTTP request details (IP address and browser user-agent) required to transmit the map images to you. No other personal data is shared with them.

System Requirements & Browser Support

This community map portal is built using standard, high-performance web APIs to deliver a fast and interactive experience without a massive download footprint.

Minimum Requirements

To access all features of this site, including the dynamic 3D interactive mapping canvas, your browser and device must support:

  • WebGL 2 Rendering: Crucial for hardware-accelerated vector mapping tiles.
  • Custom Elements V1 (Web Components): Used to load standard structural components like headers and footers.
  • ES Modules & Async/Await: Needed to compile and run script logics efficiently.

Supported Browser Versions

We actively support and optimize for the following browser baselines on desktop and mobile:

  • Apple Safari: Version 15 or later (macOS 10.15+, iOS 15+, iPadOS 15+)
  • Google Chrome: Version 93 or later (Windows, Linux, macOS, Android 6.0+)
  • Mozilla Firefox: Version 65 or later (All platforms)
  • Microsoft Edge: Version 93 or later (All platforms)

Graceful Degradation Note: If your web browser does not support WebGL 2 but supports modern JavaScript (Custom Elements V1), you can still fully use our Public Directory to search local establishments, find phone numbers, call businesses, and open directions. Only the interactive map rendering canvas itself will be disabled.
