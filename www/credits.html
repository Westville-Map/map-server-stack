Credits & Acknowledgements

The Welcome to Westville Map Project is made possible by aggregating excellent open-source libraries, open datasets, and robust free public services. We proudly credit and thank the following projects:

OpenStreetMap

Data License: ODbL

Provides the underlying collaborative, crowdsourced geographic database used for rendering streets, paths, buildings, and land use types across the map style.

Copyright & License ↗ Official Website ↗

Esri / ArcGIS World Imagery

Data License: Esri Terms

Serves our high-resolution satellite basemap overlay, compiled from global commercial imagery, aerial photography, and community-contributed datasets.

Official Website ↗

OpenFreeMap

Server License: MIT

The incredible vector tile hosting infrastructure and style renderer that lets us run beautiful, custom map styles without commercial subscription limits.

Official Website ↗

MapLibre GL JS

Software License: BSD 3-Clause

The open-source, webgl-accelerated interactive map rendering library. Used as the core client-side map rendering engine for the application.

Source Code ↗ Official Website ↗

MapLibre GL Layer Control

Software License: MIT

A lightweight MapLibre plugin used to construct our elegant, responsive interactive layer-switching panel.

Source Code ↗

pdf-lib

Software License: MIT

An excellent client-side JavaScript library used to dynamically compile and format printable public directory sheets and business cards directly on the user's device.

Official Website ↗ Source Code ↗

Open Sans Typography

Font License: SIL OFL 1.1

Designed by Steve Matteson, Open Sans is our primary highly legible typeface, designed specifically for seamless mobile, print, and desktop rendering.
